# 标点表

默认表在 `punctuation-rules.js`。汉字、英文、数字不在表里：两边都不插缝，行头行尾都合法。一个字可以同时在多张表里。规则写成「在 X」「在 X 且不在 Y」，各自查表。插缝、连写、抽推、悬挂都查这些表。

流水线见 [TYPESET.md](TYPESET.md)。

| 属性 | 字符（默认） |
|---|---|
| `前有空` | `（` `【` `「` `『` `《` `〈` `〔` `［` `“` `‘` `(` |
| `后有空` | `，` `。` `、` `；` `：` `？` `！` `）` `】` `｝` `〉` `》` `」` `』` `)` `]` `}` `”` `’` `·` `;` `:` `!` `?` |
| `两侧无空` | `…` `～` `—` `％` `‰` `℃` `°` |
| `两字一体` | `…` `—`。两个相同码位成一对 `……` / `——`，中间不断开。不跟 `两侧无空`、置中表走 |
| `行头不可` | 默认无字。`jisStrict` 时填入 `ぁぃぅぇぉっゃゅょゎゕゖァィゥェォッャュョヮヵヶ` `ー` `々〻ゝゞヽヾ` |
| `置中点号` | 默认无字。`punctAlign: 'center'` 时填入 `，` `。` `、` `；` `：` `·`。是 `后有空` 的子集 |
| `置中固定` | 默认无字。`punctAlign: 'center'` 时填入 `？` `！`。是 `后有空` 的子集 |

`punctAlign` 只填/清两张置中表，前三张、`两字一体`、`行头不可` 保持原字。打开后 `。` 同时在 `后有空` 和 `置中点号`；`？` 同时在 `后有空` 和 `置中固定`；`…` `—` 同时在 `两侧无空` 和 `两字一体`；`」` 只在 `后有空`。关着两张置中表为空。置中用于横排。两张置中表的填字是固定清单，自定义 `gapAfter` 改的是 `后有空`。半角 `!?` 在 `后有空`。半角 `,` `.` 不在这三张表里。

在 `Katsuji.apply` **之前**设好 `punctAlign`。中途改表后整篇重跑 `apply`。

```js
Katsuji.setPunctConfig({ punctAlign: 'center' }); // 默认 'corner'
```

`setPunctConfig` / `applyPunctPreset('jis-strict'|'vertical')`：JIS 严格只填 `行头不可`，不改前三张；竖排把 `？` `！` 改成 `两侧无空`，并加上竖排形标点。`punctAlign` 另填两张置中表。

## 派生

| 属性 | 判定 |
|---|---|
| `不能在行头` | 在 `后有空` 或 `两侧无空` 或 `行头不可` |
| `收半角` | 在 `后有空`，且不在两张置中表 |
| `行尾非法` | 在 `前有空` |
| `行首只锁前缝` | 在 `置中点号` |
| `可悬挂` | 见 [HANG.md](HANG.md) |

## 插缝

可叠时按此优先，只决定缝在哪：

1. 在 `置中固定` 或 `两侧无空` → 两边都不插
2. 在 `置中点号` → 两边都插
3. 在 `前有空` → 前
4. 在 `后有空` → 后

`'both'` 时邻字之间最多两条缝（前字后缝 + 后字前缝），同一侧只留一条。

## 两字一体

查 `两字一体` 表，相邻两个相同码位收一对。从左每两个收一对，多一个单独留着。整对可以在行尾。单个 `…` / `—` 仍只是 `两侧无空`。`…—`、`％℃` 不绑。不是收半角成对，中间没有缝。JIS 严格只填 `行头不可`，不改这张。竖排只改前三张。

## 行头不可

默认空表（宽松：小假名可以在行头）。`jisStrict` 只填这张表，不改 `两侧无空`。表里的字只参与 `不能在行头`：不是标点，不插缝，第 4 步不成对。

## 锁缝

- **行尾锁后缝：** 行尾已包半角盒或居中半角盒时，后面那条缝清零并标成不再摊。
- **挂出锁前缝：** 行尾已推出时，前面那条缝清零并标成不再摊。未挂的置中点号前缝仍是行内缝，按 [MEASURE.md](MEASURE.md) 可摊。
