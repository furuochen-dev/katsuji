# 量宽

第 5 步用这里的公式和 selector。步骤见 [TYPESET.md](TYPESET.md)。盒怎么包见第 5 步。

## 行宽

行宽是**正文框**。量内容盒（`clientWidth − padding`）。

- 左右都加了 0.5em 悬挂沟时，量到的盒子已经不含沟，直接当行宽。
- 只加一侧时，量到的盒子再减去那 0.5em（例如只右加：27.5 − 0.5 → 27）。
- 段首行再减 `text-indent`。
- 行宽不低于本行的合。沟只吃摊剩的空白。

## 合、半、基数

```
合     = 字 + 空 − 半
压入量 = 基数 + 合 − 行宽
推出量 = 基数 + 行宽 − 合
```

- **字：** DOM 逐字加
- **空：** 本行缝的 padding/margin
- **半：** 盒比字少占的内口
- **基数：** 这些字**挪完之后**在正文框里的占宽

字按所在行计。未包的字先按 1em：汉字、`前有空`、`两侧无空`、置中点号 / 置中固定未挂都是 1em。

半的算法：可悬挂 → 1；否则收半角或置中点号 → 0.5；否则 0。

| 盒 | 占内口 | 半 | 基数相对未包 |
|---|---|---|---|
| 未包（含置中点号 / 置中固定未挂） | 1em | 0 | 0 |
| 半角顶格（收半角且不可悬挂） | 0.5em | 0.5 | ±0.5 |
| 已推出（可悬挂 / 左挂） | 0（不占正文框） | 1 | ±1 |

包半角：收半角且不可悬挂 −0.5 / +0.5。可悬挂占内口 0，−1 / +1。半角盒的折行宽度是 0.5em；盒外溢出的墨在行宽之外。

例：合 27em，行宽 27em。抽 `」。`：2 − 0.5 连写 − 1 悬挂 = 0.5。压入量 = 0.5 + 27 − 27 = 0.5，行内挤 0.5em。置中表有字时抽未挂的 `。`：行尾包居中半角，基数 0.5em；抽可挂的 `。`：基数 0；抽未挂的 `？`（置中固定）：基数 1em。压入上限 0.6em。满行只差不到 0.4em 却抽一个整字时，压入超过 0.6em，走下面 selector 的改推。满行抽可挂的 `。` 基数是 0；满行抽 `」`（`hangRight: 'stops'`）基数是 0.5。

## 挪完再扣连写

挪完会出现新的成对标点（[TYPESET.md 第 4 步](TYPESET.md#4-标点连写间距收缩每行只看行内)）。每收一处从基数里减 0.5em。扣多少跟成对判定走（置中 `。」` 收右扣 0.5，`）」` 收左扣 0.5）。

- **压入：** 原行尾 + 抽上来的第一个字；以及抽上来的那一串内部（下一行还没做第 4 步，串内尚未收）。抽完立刻按第 4 步收这些对：接缝和串内都收。抽上来还没折到本行时也先收，折行器才能看见少掉的 0.5em。
- **推出：** 推下去的最后一个字 + 原下一行行头。串内若本行第 4 步已经收过，已在「合」里。

抽/推一个字：它的前缝、后缝跟着走。抽上来后，行首置中点号的前缝解锁、变成接缝。推到下行行首，下行第 3 步再锁。

## selector

- 压入不超过 0.6em（允许多 0.01em）。超过上限：有推出就推；没有推出就保持本行。
- 压入量 ≤ 0（剩余已够放下）：仍压入，行内缝保持原宽。没有可调缝也可以。剩余摊到**正文右缘**。第 4 步连写省下的 0.5em 计入正文剩余。
- 压入量 > 0：用可调缝来摊，挤还是推看哪边每条缝摊到的绝对值更小，差不多时挤。
- 推出量是正数、且每条缝分到至少 0.01em，才推出。

摊剩余：用第 4 步收之前还在本行的那一串字，抽完/挂完之后的合对行宽。这一串还在本行时再摊。

## 哪些缝摊

压入、推出都改本行**行内缝**。

- **压入：** 行尾后面那条已经锁死，保持 0。本行没有行内缝时：压入量 > 0 改推或保持本行；压入量 ≤ 0 仍压入。抽上来后，接缝若还在（没被连写删掉）算行内缝。置中点号在行中时前缝、后缝都摊；接缝两条都留、都摊（点号前缝 + 上行后缝）。
- **推出：** 行最末按推完留下来的最后一字算。它后面那条、将挂则它前面那条、行首已锁死的缝保持原宽。本行末尾被推走的 `前有空` 前面那条，推完是下一行开括号缝，留给下行第 3 步。已经收进半角盒的那一侧空已经去掉，不再占一条缝。
