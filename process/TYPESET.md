# 排版过程

先 `Katsuji.apply`，再 `Katsuji.applyHangAvoidance`。切缝扫根下文本（跳过 `pre` / `code` 等）；挤推、撑行只动段落、标题、列表。

标点集合见 [PUNCT.md](PUNCT.md)。行宽、合、selector 见 [MEASURE.md](MEASURE.md)。悬挂档位见 [HANG.md](HANG.md)。

Demo「下一步」一次做完**一行**的第 3–5 步。纯规则在 `typeset-rules.js`。入口：`applyHangAvoidance` · `processLine` · `trySpaceOnEdgeStart` · `applyComboSymbolsOnLine` · `applyLineEndOnLine`。

## 顺序

1、2 对整篇文章做一次。`applyHangAvoidance` 开头先清掉上一轮挤推、半角盒（含连写收的），补回连写删掉的缝，以及上一轮加上去的悬挂 padding。

至少一侧要挂时，每个挤推块先做 **2′**，再从第一行做到倒数第二行：一行上先 3、再 4、再 5。第 5 步看**还没处理的下一行**，所以从前往后。

| 谁 | 做什么 |
|---|---|
| 非段末行 | 3、4、5 |
| 段末行 | 3、4；短行保持短 |

两侧都关悬挂：跳过 2′，第 3、5 步与未开悬挂相同。第 3、4 步只处理本行里的字；跨行的 `」` / `「` 各在自己那一行成对。

## 1. 标记可调整空间（整篇）

在标点外侧插宽度为 0 的缝，后面全靠改这条缝的空白来挤、推。插哪一侧见 [PUNCT.md · 插缝](PUNCT.md#插缝)。`splitTextWithMarkers` 和 `restoreMissingGaps` 走同一套侧。同一段字跑一遍；重跑只补缺的缝。`<ruby>` 整簇不切缝；量宽扫底、不扫 `<rt>`。合里一颗 ruby 按这一行的盒宽计一次。

`Katsuji.apply` · `segmenter.js`

## 2. 暂时禁用浏览器自动断行（整容器）

浏览器会把 `不能在行头` 拽回上一行，后面的修正就看不到行首禁则。把容器设成任意字都可以折行（`line-break: anywhere`），并保持到排完。`<ruby>` / `<rt>` 不继承这句，断行仍交给 UA。

`relaxBuiltinLineBreak` · `line-break.js`

## 2′. 留悬挂沟（每块一次；至少一侧要挂才做）

在块现有 padding 上左右各再加 0.5em。沟叠在作者边距外面。行宽按 [MEASURE.md](MEASURE.md) 用正文框，沟只吃摊剩。关掉悬挂或重跑前，只减掉我们加的那两侧。重跑只加一次。左右都加，为了对称。作者的 `text-indent` 保持原样。左挂两档只决定第 3 步要不要再推盒。

例如：原来 0 → 0.5em；原来 0.2em → 0.7em；原来 1em → 1.5em。

未传入 `hangingPunctuation` 时跳过这一步。档位见 [HANG.md](HANG.md)。

## 3. 行首开括号顶格（每行）

行首是 `前有空`：清掉它左边的前空并标成不再动；包一个 0.5em 宽的窗口，里面的字左移半个字，只露出右边的墨。段首行也做：缩进还在，开括号不再带着前空。不是段首行时，把开括号和后面**第一个字**绑进同一个 `inline-block`。只绑这一个字。

行首字在 `置中点号`：只锁前缝（宽 0、标成不再摊），不裁盒。表空则没有任何字走这句。抽离行首后解锁，前缝变接缝。

左挂两档，作者的 `text-indent` 都保持原样：

- **`hangLeftIndent`：** 打开悬挂时的默认。段首行且 `text-indent ≥ 0.5em` 时再推盒，墨进缩进。缩进不足 0.5em 时跳过。
- **`hangLeft`：** 默认关。每一行（含段首）再推盒，墨进 2′ 左沟。段首若同时也开了缩进左挂，先吃缩进，余下的进沟。

要推时：先绑进同一个 `inline-block`，再把这个 0.5em 盒向左推 0.5em，占内口 0。合、基数按占内口 0 计。后一字若是标点，第 4 步可能把它也收成半角，原子盒变成约 0.5em；上一行剩余够时整对抽上去。

推盒是负 margin，缩进还在。

```
（文本文本文本...
```

`trySpaceOnEdgeStart`

## 4. 标点连写间距收缩（每行，只看行内）

只把 `两字一体` 表里成对的字绑成不折的一段：`……`、`——` 各一对。连续 `两侧无空` 不一律绑（`…—`、`％℃` 要能分开）。只收本行里的缝。判定见 [PUNCT.md · 两字一体](PUNCT.md#两字一体)。`glueTwoEmKeepPairs` · `combo.js`

成对：

- 左字「收半角」且右是标点 → 成对，收左（`）」` `）。` `）（`）
- 左字在 `置中点号` 或 `置中固定`、右在 `前有空` → 成对，收右（`，「` `。「`：开括进半角盒）
- 左字在 `置中点号` 或 `置中固定`、右字「收半角」 → 成对，收右（`。」` `？」`：闭括进半角盒，点号仍 1em）
- 其余不成对（`。，` `？！`）。`…（` 左字不在置中表，仍收左

收左：把**前面那个字**收成半角盒，中间第一条缝删掉。收右：把**后面那个字**收成半角盒，删紧挨它的那条缝。合少 0.5em；折行器看见的也是 0.5em。前面已经是半角盒（比如行首顶格）时，改收后面那个字。`收半角` 的盒露左墨；`前有空` 和行首顶格一样，盒里左移半字只露右墨。可调空只数还在的缝。

**4.1** 收左且中间有两条缝（如 `）（`）：只删**前一条**（后有空后面那条），后一条留下；左字进半角盒。

```
文本）（文本文本...
```

**4.2** 收左且中间一条缝：删掉这一条，前面的字进半角盒。外侧其它缝留下。

```
文本）」文本
```

**4.3** 收右（置中点号 / 置中固定 + 开括或闭括，如 `，「` `。」`）：删紧挨右字的那条，右字进半角盒；点号仍 1em。半角盒占内口 0.5em，折行宽度也是 0.5em。盒外溢出的墨按 [MEASURE.md](MEASURE.md) 不计入行宽。

收完若下行字折上来、本行又有成对，再扫，直到本行没有可收的。收完本行后缀若被折到下行，第 5 步按收之前的行尾和原下行行头判定。`applyComboSymbols` 与抽上来那次收对用同一套成对判定。

`applyComboSymbolsOnLine` · `combo.js`

## 5. 行尾处理（每行；段末行做完 3、4 即止）

看下一行行头，分 5.1 / 5.2。做完用 [MEASURE.md · selector](MEASURE.md#selector)。包半角的 DOM 打「收半角」；挂的 DOM 打「可悬挂」。

| 行尾做成 | 盒 | 占内口 | 半 | 锁缝 |
|---|---|---|---|---|
| 收半角（成对闭） | 0.5em，左对齐露左墨 | 0.5 | 0.5 | 后缝 |
| 挂成对闭 | 同上，再推出 0.5em | 0 | 1 | 前缝、后缝 |
| 挂置中点号 | 0.5em 居中（`margin-left: -0.25em`），再推出 0.5em | 0 | 1 | 前缝、后缝 |
| 未挂的置中点号（`：` `；` `·`，以及未开悬挂的 `，。、`） | 同样的居中半角盒，不推出 | 0.5 | 0.5 | 后缝；前缝留下当行内缝 |

沟宽仍 0.5em。抽上来或推完留下的最后一个字：可悬挂、收半角或置中点号都包盒。置中点号用居中半角盒；可挂再推出 0.5em。已挂出时剩余摊进其余行内缝，盒顶在行边进沟。

### 5.1 下一行行头是 `不能在行头`

禁则打头：把下一行行头那些禁则抽回来，或把本行尾连禁则一起推下去。

**推出基数：** 从本行行尾往回，连续的 `不能在行头`（可以是 0 个），再加上再往前那一个可以出现在行头的字；再扣掉推出造成的连写。推完之后看**现在的本行行尾**：可悬挂则挂（半 1）；收半角则包半角盒（半 0.5）。

**压入基数：** 从下一行行头往下，连续的 `不能在行头`，碰到可以出现在行头的字就停；再扣掉压入造成的连写。若抽出的最后一个可悬挂或收半角，包对应的盒；可悬挂 −1，收半角 −0.5。

### 5.2 其余情况：撑行

下一行行头可以出现在行头。用抽下一行来填本行；抽不动或抽太多就改推。

**压入基数：** 下一行行头连续的 `前有空`（可以是 0 个），再往后一个不是 `前有空` 的字（若是 `<ruby>` 按这一行的盒宽，不是 1em），再往后连续的 `不能在行头`；再扣掉压入造成的连写。抽出的最后一个若可悬挂或收半角，包对应的盒；可悬挂 −1，收半角 −0.5。开括和随后的禁则一起抽上来。抽不动时看**现在的本行行尾**：可悬挂则挂。

**推出基数：** 本行行尾连续的 `前有空`（可以是 0 个）；再扣掉推出造成的连写。推完看**现在的本行行尾**（没推走字就是现在这个尾）：可悬挂则挂，收半角且还没包盒则包半角盒。已经是半角盒的，合里不再加包盒；可悬挂仍推出。
